# LiteCut


LiteCut is an ~~(untested)~~ video editor like CapCut but very lightweight and for Android 4.1+.

<div align="center">
  
### ***The project was made by Claude (AI). If you don't like it, then don't use it. I'm not forcing you to use it anyways.***

## LiteCut introduces some features from (partitally) CapCut, like:
### Filters (only basic filters)
### Timeline Scrubber (will be in first release)
### *(Bottom)* Text Overlay
### Trimming
### Speed (from 0.25x to 4x)
### Rotate / Flip
### Crop to ratio
### Brightness, contrast, and saturation editing
### Fade in / out
### Volume editing (partitally because it can for now only mute)
### Exporting to 720p 60fps maximum
